# Morse Code Converter

This project is a **C++ program** that converts **text to Morse code** and **Morse code back to text**. It also includes an option to play Morse code using sound.

## Features
✅ Convert English text to Morse code  
✅ Convert Morse code back to text  
✅ Play Morse code as sound using `Beep()`  
✅ Interactive menu for user input
